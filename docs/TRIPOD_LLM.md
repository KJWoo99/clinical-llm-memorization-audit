# TRIPOD-LLM 대응표

TRIPOD-LLM(Gallifant 등, Nature Medicine 2025;31:60-69, 표 2)의 항목을 이 저장소의 어디에서 다루는지 적음.
원문 요약은 19개 주항목, 50개 세부항목이라고 적지만 표 2 의 행은 49개이고, 그 49개를 전부 옮김. 항목 문구는 원문을 줄여 옮김. 지침은 연구 설계와 LLM 과제에 따라 적용 항목이
달라지는 모듈 방식임. 이 연구의 설계는 "LLM evaluation"(이미 있는 LLM 을 의료 과제에서 평가, 지침의 E)이고,
과제는 퇴원요약문에서 약 이름을 뽑는 "text processing"(개체 추출)임. 지침의 H(실제 진료 흐름 안의 평가),
M(LLM 방법론), D(새 LLM 개발)가 아님.

"적용" 칸이 해당없음이면 지침의 설계, 과제 표시상 이 연구에 걸리지 않는 항목임. 걸리는데 다루지 않은
항목은 "보고하지 않음" 과 이유를 적음.
